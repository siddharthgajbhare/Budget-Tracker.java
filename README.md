# 💰 Personal Budget Tracker

A console-based **Personal Budget Tracker built with Java** to manage income, expenses, monthly budgets, and financial reports. This project helps users monitor their spending habits, track transactions, and maintain better control over their finances.

## 🚀 Features

- 💵 **Income Management** — Add and manage income transactions.
- 💸 **Expense Tracking** — Record expenses with categories, descriptions, and dates.
- 📊 **Financial Summary** — Calculate total income, expenses, and current balance.
- 🎯 **Monthly Budget Management** — Set category-wise budgets and receive overspending warnings.
- 📅 **Monthly Reports** — View monthly income, expenses, and net savings.
- 🗂️ **Category Analysis** — Analyze income and expenses by category.
- 🔍 **Transaction Search** — Search transactions using keywords.
- 🗓️ **Date Filtering** — Filter transactions by a date range.
- 🗑️ **Delete Transactions** — Remove transactions using their IDs.
- 💾 **CSV File Storage** — Save and load financial records.
- ✅ **Input Validation** — Handle invalid amounts, dates, and other input errors.

## 🛠️ Tech Stack

- **Language:** Java
- **Core Concepts:** Object-Oriented Programming (OOP)
- **Collections:** ArrayList, EnumMap, List, Map
- **Java APIs:** Java Time API, Java Streams
- **File Handling:** Java NIO, CSV
- **Financial Calculations:** BigDecimal
- **Interface:** Console-based menu

## ⚙️ Getting Started

### Prerequisites

- Java JDK 11 or later
- VS Code, IntelliJ IDEA, Eclipse, or any Java IDE
- Git installed on your system

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Open the project directory**

```bash
cd Personal-Budget-Tracker
```

**3. Compile the Java files**

```bash
javac Main.java BudgetTracker.java Transaction.java
```

**4. Run the application**

```bash
java Main
```

> Note: These commands assume that the Java files are in the same directory and that `Main.java` contains the main method.
